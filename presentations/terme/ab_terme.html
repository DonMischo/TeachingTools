= Wahr oder falsch?

Name: ____________________   Klasse: ______   Datum: __________

Eine Gleichung aus zwei Termen ist eine wahre Aussage, wenn beide Seiten nach dem Zusammenfassen gleich sind – dann stimmt sie für jede Zahl, die man einsetzt. Sonst ist sie falsch.

3a + a = 4a✓ wahrlinks 4a, rechts 4a
a + a = a²✗ falscha + a = 2a, aber a² = a · a
2 · 3a = 6a✓ wahrZahlen mal Zahlen
a + b = ab✗ falscha + b bleibt a + b
a · b = ba✓ wahrReihenfolge egal
2a · 3b = 5ab✗ falsch2 · 3 = 6, nicht 5
−(a − b) = b − a✓ wahrlinks −a + b
a − (b + c) = a − b + c✗ falschMinusklammer: − c
So gehst du vor
① Linke Seite so weit wie möglich zusammenfassen.
② Rechte Seite so weit wie möglich zusammenfassen.
③ Vergleichen: gleich → wahr (stimmt für jede Zahl) · verschieden → falsch.
Tipp: Eine Zahl einsetzen? Verschiedene Ergebnisse → sicher falsch. Gleiche Ergebnisse beweisen nichts: a = 2 ergibt bei a + a = a² links 4 und rechts 4!

² Klammern quadrieren

Name: ____________________   Klasse: ______   Datum: __________

Ein Quadrat ist Klammer mal Klammer: (x + d)² = (x + d) · (x + d). Jedes Glied mal jedes: ① vorne · vorne, ② vorne · hinten, ③ hinten · vorne, ④ hinten · hinten. Bei a(x + d)² + e: erst quadrieren, dann mal a, dann + e.

(x + d)² = (x + d) · (x + d)Quadrat = mal sich selbst
(x + 3)² = x² + 3x + 3x + 9① x·x ② x·3 ③ 3·x ④ 3·3
(x + 3)² = x² + 6x + 9Mitte zusammen – nicht x² + 9!
(x − 3)² = x² − 6x + 9(−3) · (−3) = +9
(x + 1)² − 4 = x² + 2x − 3e zur Zahl am Ende
2(x + 1)² = 2x² + 4x + 2erst quadrieren, dann mal a
−(x + 1)² = −x² − 2x − 1Minus davor dreht alle
(x + d)² = x² + 2dx + d²allgemein
Binomische Formeln – die Abkürzung
(a + b)² = a² + 2ab + b²1. binomische Formel
(a − b)² = a² − 2ab + b²2. binomische Formel
(a + b) · (a − b) = a² − b²3. binomische Formel: die Mitte hebt sich weg
